## Technical Background

MatterGen employs a diffusion-based approach for crystal structure generation, utilizing classifier-free guidance to steer the generation process. The core of our modifications centers on the `PropertyGuidedPredictorCorrector` class in `magnetic_guidance.py`, which implements a sophisticated guidance mechanism:

```python
# magnetic_guidance.py
class PropertyGuidedPredictorCorrector(GuidedPredictorCorrector):
    def __init__(self, guidance_scale, reward_function, diffusion_module,
                 predictor_partials, corrector_partials, device, n_steps_corrector,
                 N=1000, eps_t=1e-3, remove_conditioning_fn=None, keep_conditioning_fn=None):
        super().__init__(...)
        self.reward_function = reward_function
        self.guidance_scale = guidance_scale
        
    def _get_score(self, batch: dict, t: torch.Tensor) -> dict:
        # Get base scores from parent class
        base_scores = super()._get_score(batch, t)
        
        # Compute reward using provided reward function
        reward = self.reward_function.compute_reward(batch)
        
        # Scale and reshape reward to match score dimensions
        for key in base_scores:
            if key in ['pos', 'cell']:  # Apply to continuous variables
                scaled_reward = reward.view(-1, 1, 1) * torch.ones_like(base_scores[key])
                base_scores[key] = base_scores[key] + scaled_reward
                
        return base_scores
```

The implementation uses specialized predictors and correctors from MatterGen's existing codebase, each designed for different structural components:

1. **Atomic Positions (`pos`)**:
   ```python
   'pos': WrappedAncestralSamplingPredictor(corruption, score_fn)
   ```
   - Reuses MatterGen's continuous variable sampler
   - Implements ancestral sampling with the update rule:
     \[
     x_{t-1} = \mu_\theta(x_t, t) + \sigma_t z, \quad z \sim \mathcal{N}(0, I)
     \]
     where \(\mu_\theta\) is the learned mean and \(\sigma_t\) is the noise schedule
   - Applies Langevin dynamics in correction step:
     \[
     x_{i+1} = x_i + \frac{\epsilon}{2}\nabla\log p(x_i) + \sqrt{\epsilon}z_i
     \]
     where \(\epsilon\) is the step size and \(z_i \sim \mathcal{N}(0, I)\)

2. **Cell Parameters (`cell`)**:
   ```python
   'cell': LatticeAncestralSamplingPredictor(corruption, score_fn)
   ```
   - Leverages MatterGen's specialized lattice predictor
   - Uses a modified ancestral sampling that preserves lattice constraints:
     \[
     L_{t-1} = \text{symmetrize}(\mu_\theta(L_t, t) + \sigma_t Z)
     \]
     where \(L\) is the lattice matrix and \(\text{symmetrize}\) enforces crystal symmetry

3. **Atomic Numbers (`atomic_numbers`)**:
   ```python
   'atomic_numbers': D3PMAncestralSamplingPredictor(
       corruption, score_fn, predict_x0=True
   )
   ```
   - Utilizes MatterGen's discrete diffusion implementation
   - Implements D3PM (Discrete Denoising Diffusion) with transition matrix:
     \[
     Q_t(x_t|x_0) = v_t v_t^\top + (1-\|v_t\|_2^2)I
     \]
     where \(v_t\) is the corruption vector at time t
   - Direct x₀ prediction mode enables better categorical sampling:
     \[
     p_\theta(x_{t-1}|x_t) = \sum_{x_0} p(x_{t-1}|x_t,x_0)p_\theta(x_0|x_t)
     \]

The guidance mechanism combines these samplers with our reward function:

\[
\text{score}_{\text{guided}}(x, t) = \text{score}_{\text{base}}(x, t) + \lambda R(x)
\]

where:
- \(\text{score}_{\text{base}}\) is the original MatterGen score function
- \(\lambda\) is the guidance scale
- \(R(x)\) is our reward function
- \(t\) is the diffusion timestep

Key implementation features:

1. **Separate Variable Handling**:
   - Continuous variables (positions, cell) receive direct reward scaling
   - Categorical variables (atomic numbers) use specialized D3PM guidance
   - Each component maintains its physical constraints

2. **Corrector Steps**:
   ```python
   corrector_partials={
       'pos': lambda corruption, n_steps, score_fn: WrappedLangevinCorrector(
           corruption=corruption,
           score_fn=score_fn,
           n_steps=n_steps,
           max_step_size=1e6,
           snr=0.4
       )
   }
   ```
   - Langevin dynamics for position refinement
   - Signal-to-noise ratio (snr) control
   - Multiple correction steps (n_steps=10)

3. **Conditioning Control**:
   - `remove_conditioning_fn`: Sets unconditional embedding
   - `keep_conditioning_fn`: Maintains conditional embedding
   - Enables classifier-free guidance mechanism

4. **Timestep Management**:
   - Uses 1000 diffusion steps (N=1000)
   - Small final timestep (eps_t=1e-3) for precision
   - Progressive denoising with controlled step sizes

## Initial Approach: Multi-Component Optimization

Our first attempts focused on simultaneously optimizing all structural components through a complex reward function:

```python
# Early version of reward computation
def compute_reward(self, batch: dict) -> torch.Tensor:
    structures = self._batch_to_structures(batch)
    rewards = []
    
    for structure in structures:
        prediction = self.chgnet_model.predict_structure(structure)
        mag_moment = float(sum(prediction['m']))
        volume = structure.volume
        mag_density = mag_moment / volume
        
        # Complex multi-term reward
        density_reward = -torch.exp(torch.tensor(abs(mag_density - self.target_density)))
        moment_reward = torch.tanh(torch.tensor(mag_moment / 10.0))
        volume_diff = (volume - self.target_volume) / self.target_volume
        volume_reward = -volume_diff * volume_diff
        
        reward = (self.density_weight * density_reward + 
                 self.moment_weight * moment_reward +
                 self.volume_weight * volume_reward)
        rewards.append(reward)
    
    return torch.tensor(rewards, device=batch['pos'].device)
```

This approach yielded modest results:
- Maximum density: 0.141 μB/Å³
- Inconsistent performance
- Competing objectives led to suboptimal solutions

## The Pivot: Atom-Only Guidance

A critical breakthrough came from analyzing MatterGen's architecture: the categorical nature of atomic number selection meant that guidance on this component could be more direct and effective than continuous variables.

We simplified our approach to focus solely on atomic rewards, implementing a new `MomentMaximizationReward` class with progressive scaling:

```python
# tune_magnetic_moments.py
class MomentMaximizationReward(BaseRewardFunction):
    def __init__(self, moment_weight: float = 1.0, chgnet_model=None):
        self.moment_weight = moment_weight
        self.chgnet_model = chgnet_model or CHGNet.load()
        
        # Progressive thresholds and multipliers
        self.thresholds = [
            (5.0, 2.0),   # 2x bonus above 5 μB
            (10.0, 3.0),  # 3x bonus above 10 μB
            (13.0, 4.0),  # 4x bonus above 13 μB
            (15.0, 5.0)   # 5x bonus above 15 μB
        ]
```

The reward computation follows:

\[
R(x) = \left(\frac{m^5}{N^4}\right) \cdot \prod_{i} B_i(m)
\]

where:
- \(m\) is the total magnetic moment
- \(N\) is the number of atoms
- \(B_i(m)\) are threshold bonus functions:
  \[
  B_i(m) = \begin{cases}
    k_i & \text{if } m > t_i \\
    1 & \text{otherwise}
  \end{cases}
  \]

The implementation of this reward function:

```python
def compute_reward(self, batch: dict) -> torch.Tensor:
    structures = self._batch_to_structures(batch)
    rewards = []
    
    for structure in structures:
        prediction = self.chgnet_model.predict_structure(structure)
        mag_moment = float(sum(prediction['m']))
        num_atoms = len(structure)
        
        # Base reward with fifth power scaling
        base_reward = (mag_moment ** 5) / (num_atoms ** 4)
        
        # Progressive threshold bonuses
        for threshold, multiplier in self.thresholds:
            if mag_moment > threshold:
                base_reward *= multiplier
        
        # Alignment bonus
        alignment = compute_alignment(prediction['m'])
        if alignment > 0.8:
            base_reward *= 2.0
            
        rewards.append(base_reward)
    
    return torch.tensor(rewards, device=batch['pos'].device)
```
